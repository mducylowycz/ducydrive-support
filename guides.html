Prepare a drive for ordinary files

Know before starting: free formatting is limited to compatible drives up to 2 GiB, FAT12/FAT16, an MBR layout, Quick mode and Data use. Other supported formatting setups, including FAT32, exFAT and NTFS, require the one-time Premium purchase. Compare all Free and Premium tools.

  1. Save important files to a separate drive first. Formatting erases the target.
  2. Connect the USB drive through a compatible OTG adapter, allow USB access and inspect it.
  3. Choose a format supported by the receiving device. FAT32 has a per-file limit of 4 GiB minus one byte. exFAT supports larger files when the receiving device supports exFAT. Consult that device's manual.
  4. Try a sample setup first if you want to explore the choices without changing files. Review the actual drive name, capacity and planned setup before confirming an erase.
  5. Wait for completion and read the verification result before disconnecting.

For Mac-only questions, use Mac storage guidance. HFS+ is experimental and non-journaled; APFS inspection reads metadata and does not create APFS, Time Machine disks or macOS installers.

Premium drive-image operations

Keep an independent backup

A file copy saves chosen files. A raw drive image copies the drive's addressed contents and layout; it needs space for the image and is not automatic recovery of deleted files.

  1. Inspect the source drive and check destination space.
  2. Choose a verified image backup where supported and wait for its result.
  3. Export app-private images and their checksum manifests with File Explorer.
  4. Keep the exported copy on another device or drive before erasing the original.

Private DucyDrive files are removed when you uninstall or clear app storage. A Recovery folder or metadata snapshot is not an independent backup and cannot recover overwritten contents.

Always-free File Explorer

Find, preview and copy files

  1. Open Files, or Open File Explorer on Dashboard. Home chooses accessible device storage automatically; DucyDrive files remain available if shared access is not enabled.
  2. Enable device storage access through Android Settings when needed. Return to DucyDrive to browse, use Locations, and search the current folder or subfolders.
  3. Tap a file to preview it. Select items, choose Copy selected and a destination, then review the plan. Keep both or Skip preserves existing files.
  4. Wait for copying and verification to finish. Read the result; after interruption, check completed items before retrying.

Verified moves retain originals in source-folder Recovery after copying. Recovery occupies storage and is not an independent backup. Permanent deletion is separate.

Android restricts protected system folders and other apps' private files on an unrooted phone. A Premium purchase does not remove those restrictions. Export private app files before uninstalling.
