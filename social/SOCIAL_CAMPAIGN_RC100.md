## Shared release facts

- Version 2.2.0 RC100, code 163.
- Available to Internal testers and submitted to the existing Alpha closed-test track.
- Five one-line responsive tabs: Dashboard, Guide, Settings, IP, and About.
- Current guided inspection, formatting, imaging, backup, restore, drive testing, receipts, and novice guidance.
- Local-first USB processing without root.
- Closed-test software, not production certification or a universal bootability claim.
- Formatting, restoring, destructive capacity testing, and image writing replace data on the selected drive.

Platform-specific published copy is retained in the private release repository.
