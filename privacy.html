Privacy and data handling

Privacy Policy

DucyDrive AIO USB Tools is designed around local, user-initiated USB work. The app does not upload USB contents, does not sell data, and does not include advertising or analytics SDKs.

Plain-English Summary

Local by design

USB inspection, formatting, image writing, backup, verification, wiping, repair, recovery, and diagnostic operations run on the Android device.

No account system

DucyDrive does not create user accounts and does not require a login to inspect compatible USB storage.

User-controlled files

Files selected through Android's system document picker are used only for the requested local operation.

Data Collection and Sharing

The application does not collect, sell, transmit, or share USB file contents, filenames, device serial numbers, advertising identifiers, Android identifiers, contact information, location, or account credentials. DucyDrive contains no advertising SDK, analytics SDK, crash-reporting SDK, or user-account SDK.

User-Selected Files and USB Devices

A user may explicitly select a source file or destination through Android's system document picker. DucyDrive accesses that item only to perform the selected backup, image-writing, restore, verification, or report-export operation. The app does not upload those files.

USB operations require a compatible USB mass-storage device and user permission through Android's USB host prompt. Destructive operations require an additional in-app confirmation before work begins.

Google Play Billing

The optional permanent Premium product is sold through Google Play Billing. Google Play processes the transaction and provides product, purchase-state, and purchase-token information required to grant and restore access. DucyDrive does not receive or store payment-card details.

Information Stored on the Device

Operation state, privacy-safe results, preferences, and protected recovery metadata may be stored privately on the device. Private app information is removed when the user clears the app's storage or uninstalls it. Exported reports, backups, and images remain under the user's control in the selected document provider.

Deletion and Control

DucyDrive does not maintain a remote account database. Users can remove locally stored app information by clearing application storage or uninstalling the application. User-exported files can be deleted from the location where the user saved them.

Policy Changes

If these practices change, this policy and the corresponding Google Play Data Safety declaration will be updated before the changed release is distributed.
